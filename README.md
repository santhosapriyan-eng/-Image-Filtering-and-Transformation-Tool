# 🖼️ Image Filtering and Transformation Tool

A powerful and user-friendly image processing application built with Python that allows users to apply various filters and transformations to digital images. Perfect for beginners learning image processing concepts.

## 🎯 Project Overview

Digital images are widely used in social media, education, healthcare, security, and photography. However, raw images often contain unwanted noise, low contrast, blur, or poor brightness. This tool solves these problems by allowing users to apply different image processing techniques easily.

## ✨ Features

### 🎨 Image Filters
| Filter | Description |
|--------|-------------|
| **Grayscale** | Converts color images to black and white |
| **Gaussian Blur** | Smooths images and reduces noise |
| **Edge Detection** | Identifies boundaries of objects (Canny edge detection) |
| **Sharpening** | Enhances edges and fine details |

### 🔄 Image Transformations
| Transformation | Description |
|----------------|-------------|
| **Rotate** | Rotates image by 90° clockwise |
| **Flip** | Creates mirror image horizontally |
| **Brightness Adjustment** | Increases or decreases brightness |
| **Contrast Adjustment** | Enhances or reduces contrast |

### 💾 Additional Features
- ✅ Open images (JPG, PNG, BMP)
- ✅ Save processed images
- ✅ Reset to original
- ✅ Real-time preview
- ✅ User-friendly GUI
